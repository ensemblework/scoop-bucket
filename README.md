# Ensemble Scoop bucket

```powershell
scoop bucket add ensemblework https://github.com/ensemblework/scoop-bucket
scoop install ensemblework/ensemble
ensemble login
```

`bucket/ensemble.json` is updated automatically by the `cli-release` workflow in [ensemblework/ensemble](https://github.com/ensemblework/ensemble) for every `cli-v*` release. Do not edit it by hand.
